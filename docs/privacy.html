Privacy Policy

Last updated: July 2026

This app connects to the TikTok API solely to upload content (videos and images) to the authenticated user's TikTok account as inbox drafts.

Data Collected

  • Videos and images the user explicitly selects for upload
  • TikTok API credentials (access tokens) provided by the user — stored locally in a .env file on the user's own machine, never transmitted to our servers
  • AI-generated captions (processed via the user's chosen AI provider API key)

Data Storage & Retention

  • Uploaded content is temporarily stored in a local directory during the review process and may be deleted after upload
  • A local log file records filenames, timestamps, and upload status — stored on the user's own device
  • No user data is collected, stored, or transmitted to any third-party server beyond the TikTok API and the user's chosen AI provider

Data Sharing

  • We do not sell, rent, or share user data with any third party
  • Content is sent to TikTok's servers only when the user explicitly clicks "Upload"
  • AI caption generation uses the user's own API key and is sent directly to their chosen provider
